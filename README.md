# Прайс-лист АРТЕКО

Локальное веб-приложение для ведения прайс-листа мебельной компании: материалы
(ЛДСП/МДФ/ХДФ/столешницы) с расчётом цены за м², фурнитура (петли, направляющие,
навесы и др.) с себестоимостью и розницей, ссылки на поставщиков с
автоматическим обновлением цен.

## Запуск

**Проще всего:** дважды кликните файл **`Запустить прайс-лист.bat`** в этой папке.
Откроется чёрное окно консоли — не закрывайте его, пока пользуетесь прайс-листом.
Затем откройте в браузере: **http://localhost:4173**

**Через командную строку** (если нужно):
```bash
npm start
```

Чтобы остановить сервер — закройте окно консоли (или нажмите Ctrl+C в терминале).

## Что внутри

- **Категории** (левая панель) — плитные материалы (ЛДСП, МДФ, ХДФ, столешницы)
  и штучная фурнитура (петли, направляющие, навесы). Можно добавлять свои
  категории кнопкой «+ Категория».
- **Плитные материалы** — вводите цену листа и его размеры (высота × ширина),
  площадь и себестоимость за м² считаются автоматически, розничная цена —
  с наценкой (по умолчанию ×3, настраивается в «⚙ Настройки»).
- **Фурнитура** — себестоимость и розничная цена вводятся напрямую, можно
  указать несколько артикулов (LTB, Blum и т.д.) и несколько ссылок на разных
  поставщиков для одной позиции.
- **Ссылки и автопарсинг** — у каждой позиции можно добавить одну или
  несколько ссылок на карточку товара у поставщика. Кнопка «↻» рядом со
  ссылкой обновляет цену прямо сейчас; кнопка «🔄 Обновить цены» наверху
  обновляет разом все ссылки в текущей категории.
  - **ltb.ge** — цена подтягивается точно (используется тот же API, что и сам
    сайт).
  - **Прочие сайты** — используется универсальный парсер (структурированные
    данные страницы: JSON-LD/meta-теги). Если сайт не публикует цену в
    таком виде (например, kronospan.com — это просто каталог декоров без
    цены, а не магазин), ссылка помечается как «без цены» — это нормально,
    просто у такой ссылки нет автообновления, и цену нужно вводить вручную.
- **Журнал обновлений** (внизу слева) — история всех попыток обновления цен:
  что изменилось, что не удалось и почему.
- **Экспорт в Excel** — выгружает весь прайс-лист в .xlsx, по листу на
  категорию, в похожем на привычный формат виде.
- **Импорт из Excel** — можно загрузить прайс от поставщика (.xlsx с
  колонками вроде «Название», «Цена», «Себестоимость» и т.п.) — приложение
  само распознает похожие по смыслу заголовки колонок и создаст позиции.

## Технические детали (на будущее)

- Технологии: Node.js + Express (сервер), обычный JavaScript без сборки
  (фронтенд). Хранилище — либо локальные JSON-файлы (`server/data/db/`),
  либо облачный Postgres (Neon) — переключается автоматически по наличию
  переменной `DATABASE_URL` (см. «Деплой в облако» ниже).
- Реальные данные из исходного `ARTECO прайс лист.xlsx` перенесены скриптом
  `scripts/seed-from-excel.js` (запускается один раз, вручную запускать не
  нужно — данные уже загружены).
- Если потребуется добавить парсер под ещё один сайт-поставщик — адаптеры
  лежат в `server/parsers/` (`ltb.js` — пример специализированного адаптера,
  `generic.js` — универсальный).
- На случай переустановки Windows/переноса на другой компьютер: нужен
  установленный Node.js (LTS) — https://nodejs.org, дальше `npm install` в
  этой папке один раз, и снова `Запустить прайс-лист.bat`.

## Деплой в облако (Vercel + Postgres)

Так прайс-лист становится доступен по ссылке из интернета (не только в
офисе), с настоящей базой данных вместо файлов. Пароль на вход добавляется
автоматически, как только вы зададите `APP_PASSWORD` (см. шаг 4) — без
переменной приложение остаётся открытым, как при локальном запуске.

**1. Создайте базу данных (Neon Postgres)**

Зайдите на [vercel.com](https://vercel.com), создайте аккаунт (кнопкой Sign Up,
можно через email или GitHub). В панели проекта откройте вкладку **Storage**
→ **Create Database** → **Postgres** (это Neon, бесплатный тариф достаточен).
После создания откройте вкладку **`.env.local`** / **Quickstart** этой базы и
скопируйте строку, которая начинается на `postgres://...` — это и есть
`DATABASE_URL`.

**2. Примените схему таблиц**

В той же панели Neon откройте **SQL Editor**, откройте у себя файл
[server/data/schema.sql](server/data/schema.sql), скопируйте всё содержимое,
вставьте в редактор и нажмите «Run». Это создаст пустые таблицы.

**3. Перенесите текущие данные в базу**

У себя в терминале, в папке проекта:
```bash
node scripts/migrate-to-postgres.js
```
(предварительно задав `DATABASE_URL` — в PowerShell:
`$env:DATABASE_URL="postgres://..."`, затем команда выше в той же сессии терминала).
Скрипт перенесёт все категории, позиции и историю обновлений из локальных
файлов в облачную базу.

**4. Разверните само приложение**

Установите Vercel CLI и войдите (откроется браузер для входа — это делаете
вы сами, я не могу входить в аккаунт за вас):
```bash
npm install -g vercel
vercel login
```
Затем из папки проекта:
```bash
vercel --prod
```
Первый запуск задаст пару вопросов (можно везде оставлять значения по
умолчанию — Enter). После деплоя Vercel даст ссылку вида
`https://ваш-проект.vercel.app`.

**5. Настройте переменные окружения**

В панели Vercel откройте ваш проект → **Settings** → **Environment Variables**
и добавьте:
- `DATABASE_URL` — та же строка из шага 1;
- `APP_PASSWORD` — пароль, который будете вводить при входе (придумайте свой);

После добавления переменных нажмите **Redeploy** (или снова `vercel --prod`),
чтобы они применились.

**Важно про безопасность**: приложение с этого момента доступно всем, у кого
есть ссылка И пароль. Держите пароль так же, как держали бы пароль от почты —
не пишите его в публичных местах. Ссылку `.vercel.app` можно позже заменить
на свой домен во вкладке **Domains**.
